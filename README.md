# 台灣死刑與廢死

繁體中文公共研究靜態網站。以可追溯來源區分數據、法律、組織自述與政策效果，含六大閱讀章節、可篩選年度圖表、真實任期時間帶、搜尋、來源索引及資料下載。

## 直接使用

開啟 `index.html` 即可閱讀。亦可在本目錄執行：

    python -m http.server 8000

無建置步驟、無外部JavaScript／字型／分析追蹤服務、無npm相依。腳本使用相對路徑；適用GitHub Pages repository subpath。`data/site-data.js` 內嵌三份圖表資料，使本機file URL也不需fetch。

## GitHub Pages

將本目錄公開檔案置於repo根目錄，使用main分支根目錄部署。保留`.nojekyll`。網站不依賴GitHub Actions建置。發布流程應核對commit和Pages deployment後再驗證公開URL，並檢查手機寬度、互動及CSV。

公開檔案：`index.html`、`style.css`、`app.js`、`logic.js`、`favicon.svg`、`.nojekyll`、`data/*`、`README.md`、`tests/*`。不應發布研究用原始PDF、文字抽取、私人筆記、臨時瀏覽器日誌或工作腳本。

## 更新

`index.html` 是完整可讀成品；細節採原生details，停用JavaScript仍可讀。引用就近保留直接來源，勿只加進來源索引。更新數據後同步 `data/site-data.js`，並跑資料一致性檢查；不將缺值補零，不把未完年度加入30年合計。日期變更必須重新查核，不應只更新頁首日期。

## 測試

    node tests/test_logic.cjs
    python tests/test_html.py
    node --check app.js
    node --check logic.js

自動涵蓋30年總數、年均、部分年度排除、0與null、總統批次對帳、全球+與分類加總、真實任期邊界、篩選／搜尋pure logic、來源欄位、引用覆蓋、ID／內部連結／本機檔案。

可選實際瀏覽器測試（需要Python Playwright與本機Chromium）：

    python tests/test_browser.py

此測試會啟動僅本機HTTP server，驗證1440、768、390、320px、展開內容、搜尋、篩選、重設、選單、深連結及no-JS。不存取來源網站或外部帳戶。可用環境變數`CHROMIUM_EXECUTABLE`覆蓋Chromium路徑。

本次資料／HTML／語法測試已通過。受限環境中的本機Chromium自動化腳本因Unix socket權限未跑成；改在已授權公開GitHub Pages進行實際雲端Chromium UI驗證，已通過桌面1165 CSS px及300%縮放下388 CSS px窄版（非真實手機裝置）、圖表年份／重設、搜尋命中／無結果／清除／Back、四筆未知數篩選、來源類型7筆研究／146全部、原生展開收合／重複操作、手機選單Escape／連結／重複關閉、表格局部橫捲與整頁無橫溢。CSV實際下載與本機檔逐位元相同。瀏覽器日誌只有擴充套件metadata錯誤，未見本站腳本錯誤。停用JavaScript仍有完整靜態全文的結構檢查已通過；實際no-JS瀏覽器模式未另跑。
